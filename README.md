# demo-git-jevalide

Petit dépôt de démonstration pour la formation « Deux mains sur le clavier », semaine 10 (Git).

Ce README affiche le résultat du premier commit et sert de base aux exercices.

Modifié dans VSCode pour la démonstration git add / commit / push : cette ligne fait maintenant partie du premier commit fait dans un serveur VSCode web.

Cette ligne vient d'un pull request fait dans le web GitHub depuis une branche maj-readme : c'est la façon de proposer un changement à un projet.
